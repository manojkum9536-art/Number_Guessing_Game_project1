## 🚀 About The Project

Welcome to my **Number Guessing Game!**

This is a simple console-based game developed using C programming. The computer generates a random number between 1 and 100, and the player has 5 attempts to guess the correct number.

## ✨ Features

- 🎯 Random number generation (1–100)
- 🎮 Start Game and Exit options
- 🔢 Maximum 5 attempts
- ⬆️ Too High and Too Low hints
- 🏆 Winning message
- ❌ Game Over message

## 🛠️ Technologies Used

- C Programming Language
- Visual Studio Code
- GCC Compiler

## 💻 How To Run

1. Clone this repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Open the project folder.

3. Compile the C program:

   ```bash
   gcc game_project.c -o game
   ```

4. Run the game:

   ```bash
   .\game.exe
   ```

## 🎯 How To Play

1. Select **1** to start the game.
2. Guess a number between 1 and 100.
3. Follow the hints:
   - Too Low!
   - Too High!
4. Guess correctly within 5 attempts to win.
5. Select **2** to exit.
